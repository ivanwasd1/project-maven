# Практика Maven-сборки

Учебный fork проекта JavaRush с консольной гоночной игрой. Моей задачей была настройка Maven-сборки, а не разработка самой игры.

## Мой вклад

- добавил необходимые зависимости в `pom.xml`;
- настроил ресурсы проекта;
- настроил сборку исполняемого JAR;
- добавил конфигурацию Maven-плагинов.

## Сборка

```bash
mvn clean package
```

Основной исходный код игры находился в стартовом репозитории. Этот fork сохранён как пример работы с Maven и зависимостями.
